Jason Wu

I’m an Assistant Professor in the Department of Computer Science at Purdue University. Previously, I was a Research Scientist in the Human-Centered Machine Intelligence group at Apple. I earned my PhD from the Carnegie Mellon Human-Computer Interaction Institute, advised by Professor Jeffrey Bigham. My PhD research was supported by the NSF Graduate Research Fellowship.

Before I joined CMU, I graduated from Georgia Institute of Technology in 2018 with a B.S. in Computer Science. There, I worked at the GT Ubicomp Lab and the Contextual Computing Group.

My research applies computational modeling to understand and improve how humans interact with computers.

featured projects

How can we encode expertise from HCI experts like designers into reward models and use them to improve AI?

UIClip

UIClip is a data-driven model that scores the design quality of user interfaces.

UICoder

Finetuning Large Language Models (LLMs) to generate higher quality UIs through automated compiler and VLM design feedback.

Reinforcement Learning from Designer Feedback

Developing workflows and reward models that encode professional designers' expertise.

How can machines understand user interfaces and make the more accessible to both humans and other programs?

WebUI

A dataset that links web semantics with UI structure for better understanding models.

Screen Parsing

Reverse engineers UI models from screenshots to recover hierarchy and semantics.

Never-ending Learning of User Interfaces

An agent that continually learns UI semantics by interacting with real apps.

How can we build intelligent tools to build more usable and accessible interfaces?

FrameKit

Authoring adaptive interfaces through keyframe-driven workflows for designers.

SQUIRE

Interactive UI authoring powered by slot query intermediate representations.

Towards Automated Accessibility Report Generation for Mobile Apps

Automated crawling and detection of accessibility issues in apps.

How can we build systems that detect and respond to user context?

Automatic Class Discovery for One-Shot Acoustic Classifiers

An audio-based activity recognition system that adapts its detection classes based on user interactions.

When Can Accessibility Help?

Using sensors and user interactions to predict and recommend useful accessibility features to people who could benefit.

Reflow

User-specific interaction models trained from calibration data produce personalized adaptations of app layouts.
